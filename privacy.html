Privacy policy

Last updated: October 12, 2026

Who uses this app

rclone-backup is a personal tool. Its only user is its author, the owner of the GitHub account Zycheng114514. It is not offered to anyone else.

What it accesses

With the author's permission, the app uses the Google Drive API (the drive scope) on the author's own Google Drive. It uses this access only to upload, update and delete the backup files in one backup folder, so that the folder matches the author's computer. Files deleted from the backup go to the Drive trash.

What it stores and where

The backup files are stored only in the author's own Google Drive. The access token and the backup logs are stored on the author's own computer and can be read only by the author's account.

Sharing

The data is not sold, not shared with other people, and not used for advertising. It is used only to back up the author's own files. The author may use software of the author's choice, including AI assistants, to work with the author's own data.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/Zycheng114514/rclone-backup-privacy.
